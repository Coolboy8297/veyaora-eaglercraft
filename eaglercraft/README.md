# Eaglercraft Build Folder

Place your **actual Eaglercraft build** here.

## Expected entry point

The launcher loads:

```
eaglercraft/index.html
```

## How to add your build

1. Download or build a legal, redistributable Eaglercraft client (the single-file or multi-file browser version you have permission to host).
2. Copy the files into this `eaglercraft/` folder so that the main HTML file is named `index.html` (or update `GAME_SRC` in `js/script.js`).
3. Commit and push to your GitHub Pages repository.
4. Visit the site and click **PLAY EAGLERCRAFT**.

## Notes

- Do **not** commit official Minecraft assets or any copyrighted content you do not have the right to redistribute.
- Eaglercraft is a community browser port; ensure your chosen build’s license allows public hosting.
- Large builds may take a few seconds to load on first open — the launcher shows a loading state automatically.
